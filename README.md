# Проект реализации онлайн платформы-торговой сети электроники
## В проекте реализовано:
1. Приложение electronics_network:
* в модуле models приложения описаны модели для продукта, поставщика и звена сети.
  при этом сеть имеет иерархическую структуру, в ней поставщик может иметь 1 из 3-х уровней: 
  0 уровень - завод;
  1 уровень - розничная сеть;
  2 уровень - индивидуальный предприниматель.
  Каждое звено сети ссылается только на одного поставщика оборудования.
  В модели звена сети описаны:
  - функция автоматического изменения задолженности у поставщика: при создании звена сети 
  задолженность поставщика увеличивается на сумму задолженности в создаваемом объекте 
  - функция создания поля ссылки на объект поставщика
* в модуле views приложения реализованы классы на основе ViewSet для CRUD объектов выше сказанных моделей, 
определены права доступа: только авторизованные активные пользователи имеют доступ к API, 
описан метод фильтрации объектов поставщика и звена сети по определенной стране
* в модуле urls приложения прописаны пути для контроллеров
* в модуле serializers описаны классы сериализаторов для моделей приложения
* в модуле admin описан вывод создаваемых объектов в админ-панели, на странице объекта звена сети добавлена 
ссылка на поставщика, фильтрация по названию города, функция обнуления задолженности перед поставщиком (admin action, 
при котором обнуляется и задолженность связанного поставщика)
* в модуле написаны тесты для проверки CRUD объектов выше сказанных моделей
2. Приложение users:
* в модуле management/commands/csu реализовано создание суперпользователя
* в модуле models приложения описана модель пользователя
* в модуле serializers описан класс сериализатора для модели пользователя
* в модуле urls приложения прописаны пути для контроллеров 
* в модуле views приложения реализованы классы для создания/изменения/удаления/просмотра пользователей,
определены права доступа, реализована аутентификация и авторизация пользователей с использованием JWT токенов
3. В проекте есть файл data.json с тестовыми данными для тестирования работы API

## Установка и запуск:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/ElectronicsRetailerProject.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

3. Создайте файл .env в корне проекта и добавьте туда необходимые переменные окружения, указанные в файле .env.sample.

4. Создайте и выполните миграции: ```python manage.py makemigrations```
                                  ```python manage.py migrate```

5. Выполните команду создания суперпользователя: ```python manage.py csu```

6. Запустите сервер: ```python manage.py runserver```

После запуска веб-приложение будет доступно по адресу: http://127.0.0.1:8000/

## Тесты:
Проект протестирован с помощью встроенного модуля unittest.
Чтобы запустить его (все тесты), выполните команду: ```python manage.py test```.
Покрытие кода тестами составляет 90%
